Rounding and error analysis

Definition

Floating-point model and unit roundoff

In the standard relative-error model, a rounded operation with exact result zz returns z(1+δ)z(1+\delta) for some ∣δ∣≤u|\delta|\le u. The bound uu is the unit roundoff. VSCL’s model supplies addition, subtraction, multiplication, division with a nonzero divisor, and square root on nonnegative inputs. It also requires exact addition from zero.

Lean definition
structure FPModel where
  u : ℝ
  u_nonneg : 0 ≤ u

  fl_add : ℝ → ℝ → ℝ
  fl_sub : ℝ → ℝ → ℝ
  fl_mul : ℝ → ℝ → ℝ
  fl_div : ℝ → ℝ → ℝ
  fl_sqrt : ℝ → ℝ

  /-- Additional exactness law: `fl(0 + x) = x`.

      This is not a consequence of the relative-error standard model above.
      It is included explicitly because tight recursive-summation constants use
      the first addition from zero as exact. -/
  fl_add_zero : ∀ x : ℝ, fl_add 0 x = x

  model_add :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_add x y = (x + y) * (1 + δ)

  model_sub :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_sub x y = (x - y) * (1 + δ)

  model_mul :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_mul x y = (x * y) * (1 + δ)

  model_div :
    ∀ x y, y ≠ 0 →
      ∃ δ : ℝ,
        |δ| ≤ u ∧
        fl_div x y = (x / y) * (1 + δ)

  model_sqrt :
    ∀ x, 0 ≤ x →
      ∃ δ : ℝ,
        |δ| ≤ u ∧
        fl_sqrt x = Real.sqrt x * (1 + δ)

Definition

Rounding factor γₖ

For unit roundoff uu and a nonnegative integer kk such that ku<1ku<1, define γk=ku1−ku.\gamma_k=\frac{ku}{1-ku}. In Lean, the condition that keeps the denominator positive is called gammaValid.

Lean definition
noncomputable def gamma (fp : FPModel) (n : ℕ) : ℝ :=
  (n * fp.u) / (1 - n * fp.u)

/-- Well-definedness guard for `gamma`.
    The denominator `1 - n * u` is positive iff `n * u < 1`.
    All lemmas that use `gamma` in a meaningful bound require this hypothesis.
    In practice this holds for any realistic algorithm depth, since
    u ≈ 2⁻⁵³ in double precision. -/
def gammaValid (fp : FPModel) (n : ℕ) : Prop :=
  (n : ℝ) * fp.u < 1

Definition

Backward error

A computed output x^\widehat x has backward error at most ε\varepsilon in an input norm if there is a change Δa\Delta a with ∥Δa∥≤ε\|\Delta a\|\le\varepsilon and f(a+Δa)=x^f(a+\Delta a)=\widehat x. A componentwise bound limits each entry of Δa\Delta a separately.

Lean definition
def normwiseBackwardErrorBoundedVec (n m : ℕ)
    (normIn : (Fin n → ℝ) → ℝ)
    (f : (Fin n → ℝ) → (Fin m → ℝ))
    (a : Fin n → ℝ) (xhat : Fin m → ℝ) (ε : ℝ) : Prop :=
  ∃ Δa : Fin n → ℝ, normIn Δa ≤ ε ∧ f (fun i => a i + Δa i) = xhat

Definition

Forward error

Forward error measures the difference x^−f(a)\widehat x-f(a) between the computed output and the exact output for the original input aa. Relative forward error divides the size of that difference by ∥f(a)∥\|f(a)\| when the exact output is nonzero.

Lean definition
noncomputable def forwardErrorBounded (f : ℝ → ℝ) (a xhat ε : ℝ) : Prop :=
  relError xhat (f a) ≤ ε

Matrices and factorizations

Definition

Operator 2-norm

The operator 22-norm is ∥A∥2=sup⁡∥x∥2=1∥Ax∥2\|A\|_2=\sup_{\|x\|_2=1}\|Ax\|_2. It equals the largest singular value when the domain has positive dimension.

Lean definition
noncomputable def opNorm2 {n : ℕ} (M : Fin n → Fin n → ℝ) : ℝ :=
  @norm (Matrix (Fin n) (Fin n) ℝ)
    Matrix.instL2OpNormedAddCommGroup.toNorm
    (M : Matrix (Fin n) (Fin n) ℝ)

Definition

Matrix infinity norm

The matrix infinity norm is the largest absolute row sum, ∥A∥∞=max⁡i∑j∣Aij∣\|A\|_\infty=\max_i\sum_j|A_{ij}|. It is the operator norm for the vector infinity norm.

Lean definition
noncomputable def infNorm {n : ℕ} (A : Fin n → Fin n → ℝ) : ℝ :=
  letI := Matrix.linftyOpNormedRing (n := Fin n) (α := ℝ)
  ‖(Matrix.of A : Matrix (Fin n) (Fin n) ℝ)‖

Definition

Frobenius norm

The Frobenius norm of a real matrix is the Euclidean length of its array of entries. ∥A∥F=(∑i,jAij2)1/2.\|A\|_{\mathrm F}=\left(\sum_{i,j}A_{ij}^2\right)^{1/2}.

Lean definition
noncomputable def frobNormSq {m n : ℕ} (A : RMatFn m n) : ℝ :=
  ∑ i : Fin m, ∑ j : Fin n, A i j ^ 2

/-- **Frobenius norm** as a Mathlib-backed compatibility wrapper for the
    library's function-shaped matrices.  The source of truth is Mathlib's
    Frobenius norm on `Matrix`, not a separate local norm definition. -/
noncomputable abbrev frobNorm {m n : ℕ} (A : RMatFn m n) : ℝ :=
  ‖(Matrix.of A : RMat m n)‖

Definition

Column Euclidean norm

The Euclidean norm of column jj of a real matrix AA is ∥A:,j∥2=(∑iAij2)1/2\|A_{:,j}\|_2=(\sum_i A_{ij}^2)^{1/2}. A columnwise error bound compares this norm for each perturbation column to the corresponding input column norm.

Lean definition
noncomputable def columnFrob {m p : ℕ} (A : Fin m → Fin p → ℝ)
    (j : Fin p) : ℝ :=
  frobNorm (fun i (_ : Fin 1) => A i j)

Definition

Matrix condition number in the 2-norm

For invertible AA, the matrix condition number in the 22-norm is κ2(A)=∥A∥2∥A−1∥2\kappa_2(A)=\|A\|_2\|A^{-1}\|_2. The Lean definition takes the inverse as an argument. A theorem supplies any required inverse certificate.

Lean definition
noncomputable def kappa2 {n : ℕ}
    (A Ainv : Fin n → Fin n → ℝ) : ℝ :=
  opNorm2 A * opNorm2 Ainv

Definition

Orthogonal matrix

A real square matrix QQ is orthogonal if its transpose is its inverse, so QTQ=QQT=IQ^{\mathsf T}Q=QQ^{\mathsf T}=I.

Lean definition
def IsOrthogonal (n : ℕ) (U : Fin n → Fin n → ℝ) : Prop :=
  IsInverse n U (matTranspose U)

Definition

Upper-trapezoidal matrix

A rectangular matrix RR is upper trapezoidal if Rij=0R_{ij}=0 whenever i>ji>j. For a square matrix, this is upper triangularity.

Lean definition
def IsUpperTrapezoidal (m p : ℕ) (R : Fin m → Fin p → ℝ) : Prop :=
  ∀ i j, j.val < i.val → R i j = 0

Definition

Columnwise QR backward error

Given AA, upper-trapezoidal R^\widehat R, and orthogonal QQ, the columnwise backward-error contract at cc asks for a perturbation ΔA\Delta A with A+ΔA=QR^,∥ΔA:,j∥2≤c∥A:,j∥2\begin{gathered}A+\Delta A=Q\widehat R,\\\|\Delta A_{:,j}\|_2\le c\|A_{:,j}\|_2\end{gathered} for every column jj.

Lean definition
structure HouseholderQRBackwardError (m n : Nat)
    (A : Fin m -> Fin n -> Real) (Q : Fin m -> Fin m -> Real)
    (R_hat : Fin m -> Fin n -> Real) (c : Real) : Prop where
  upper : IsUpperTrapezoidal m n R_hat
  orth : IsOrthogonal m Q
  result : Exists fun dA : Fin m -> Fin n -> Real =>
    (forall i j, A i j + dA i j = matMulRect m m n Q R_hat i j) /\
    (forall j, columnFrob dA j <= c * columnFrob A j)

Lean definition

Definition

Componentwise QR backward error

For upper-trapezoidal R^\widehat R and orthogonal QQ, the contract asks for A+ΔA=QR^A+\Delta A=Q\widehat R with ∥ΔA∥F≤cnorm\|\Delta A\|_{\mathrm F}\le c_{\mathrm{norm}}. It also requires a nonnegative GG with ∥G∥F=1\|G\|_{\mathrm F}=1 such that ∣ΔA∣≤ccompG∣A∣|\Delta A|\le c_{\mathrm{comp}}G|A| entrywise.

Lean definition
structure HouseholderQRComponentwiseBackwardError (m n : Nat)
    (A : Fin m -> Fin n -> Real) (Q : Fin m -> Fin m -> Real)
    (R_hat : Fin m -> Fin n -> Real) (c_norm c_comp : Real) : Prop where
  upper : IsUpperTrapezoidal m n R_hat
  orth : IsOrthogonal m Q
  result : Exists fun dA : Fin m -> Fin n -> Real =>
    Exists fun G : Fin m -> Fin m -> Real =>
      (forall i j, A i j + dA i j = matMulRect m m n Q R_hat i j) /\
      frobNorm dA <= c_norm /\
      (forall i j, 0 <= G i j) /\
      frobNorm G = 1 /\
      (forall i j, |dA i j| <=
        c_comp * matMulRect m m n G (fun a b => |A a b|) i j)

Definition

LU factorization

An LU factorization is a product A=LUA=LU with LL lower triangular and ones on its diagonal, and UU upper triangular.

Lean definition
structure LUFactSpec (n : ℕ) (A L : Fin n → Fin n → ℝ) (U : Fin n → Fin n → ℝ) : Prop where
  /-- L is unit lower triangular: diagonal entries are 1. -/
  L_diag : ∀ i : Fin n, L i i = 1
  /-- L is lower triangular: entries above diagonal are 0. -/
  L_upper_zero : ∀ i j : Fin n, i.val < j.val → L i j = 0
  /-- U is upper triangular: entries below diagonal are 0. -/
  U_lower_zero : ∀ i j : Fin n, j.val < i.val → U i j = 0
  /-- A = L * U: the product recovers A exactly. -/
  product_eq : ∀ i j : Fin n, ∑ k : Fin n, L i k * U k j = A i j

Lean definition

Definition

Componentwise LU backward error

The computed factors L^\widehat L and U^\widehat U have the LU triangular shapes and satisfy ∣L^U^−A∣≤ε∣L^∣∣U^∣entrywise.|\widehat L\widehat U-A|\le\varepsilon|\widehat L||\widehat U|\quad\text{entrywise}. Absolute values on matrices are taken entry by entry.

Lean definition
structure LUBackwardError (n : ℕ) (A L_hat U_hat : Fin n → Fin n → ℝ)
    (ε : ℝ) : Prop where
  /-- L̂ is unit lower triangular. -/
  L_diag : ∀ i : Fin n, L_hat i i = 1
  /-- L̂ is lower triangular. -/
  L_upper_zero : ∀ i j : Fin n, i.val < j.val → L_hat i j = 0
  /-- Û is upper triangular. -/
  U_lower_zero : ∀ i j : Fin n, j.val < i.val → U_hat i j = 0
  /-- Componentwise backward error: |L̂Û - A| ≤ ε|L̂||Û|. -/
  backward_bound : ∀ i j : Fin n,
    |∑ k : Fin n, L_hat i k * U_hat k j - A i j| ≤
      ε * ∑ k : Fin n, |L_hat i k| * |U_hat k j|

Definition

Symmetric positive definite matrix

A real AA is symmetric positive definite if A=ATA=A^{\mathsf T} and xTAx>0x^{\mathsf T}Ax>0 for every nonzero real vector xx.

Lean definition
def IsSymPosDef (n : ℕ) (A : Fin n → Fin n → ℝ) : Prop :=

  (∀ x : Fin n → ℝ, (∃ i : Fin n, x i ≠ 0) →
    0 < ∑ i : Fin n, ∑ j : Fin n, x i * A i j * x j)

Definition

Least-squares residual and objective

For data A,bA,b, the least-squares residual can be written Ax−bAx-b. The squared objective is ∥Ax−b∥22\|Ax-b\|_2^2. It has the same minimizers as ∥Ax−b∥2\|Ax-b\|_2 because squaring is increasing on nonnegative numbers.

Lean definition
noncomputable def lsResidual {m n : ℕ} (A : Fin m → Fin n → ℝ)
    (b : Fin m → ℝ) (x : Fin n → ℝ) : Fin m → ℝ :=
  fun i => rectMatMulVec A x i - b i
/-- Squared least-squares objective `||A x - b||₂²`. -/
noncomputable def lsObjective {m n : ℕ} (A : Fin m → Fin n → ℝ)
    (b : Fin m → ℝ) (x : Fin n → ℝ) : ℝ :=
  vecNorm2Sq (lsResidual A b x)

Finite-volume methods

Definition

Cell average

For an integrable field qq on an interval [a,b][a,b] with a<ba<b, the cell average is qˉ=1b−a∫abq(x) dx.\bar q=\frac1{b-a}\int_a^b q(x)\,dx. For a vector field the same formula averages all components.

Lean definition
noncomputable def oneDimensionalCellAverage
    {E : Type*} [NormedAddCommGroup E] [NormedSpace ℝ E]
    (field : ℝ → E) (left right : ℝ) : E :=
  (right - left)⁻¹ • ∫ x in left..right, field x

Lean definition

Definition

Finite-volume flux update

For positive cell volume VV, the next cell average is qˉnew=qˉold−ΔtVFout,\bar q_{\mathrm{new}}=\bar q_{\mathrm{old}}-\frac{\Delta t}{V}F_{\mathrm{out}}, where FoutF_{\mathrm{out}} is the net outward numerical flux and Δt\Delta t the time step.

Lean definition
noncomputable def finiteVolumeCellAverageUpdate
    {E : Type*} [AddCommGroup E] [Module ℝ E]
    (timeStep cellVolume : ℝ) (oldAverage netOutwardFlux : E) : E :=
  oldAverage - (timeStep / cellVolume) • netOutwardFlux

Definition

Local conservation at an interface

At each time and shared face, the outward flux from one adjacent cell is the negative of the outward flux from the other, FL=−FRF_{\mathrm L}=-F_{\mathrm R}.

Lean definition
def IsLocallyConservative
    {Cell Face Time Value : Type*} [Neg Value]
    (left right : Face → Cell) (flux : Time → Cell → Face → Value) : Prop :=
  ∀ time face, flux time (left face) face = -flux time (right face) face

Definition

Hyperbolicity of a real matrix

A real square AA is hyperbolic in the conservation-law sense if it admits a real eigenbasis viv_i with real eigenvalues λi\lambda_i satisfying Avi=λiviAv_i=\lambda_i v_i. Eigenvalues may repeat.

Lean definition
def IsRealHyperbolicMatrix {ι : Type*} [Fintype ι]
    (coefficient : Matrix ι ι ℝ) : Prop :=
  ∃ (eigenvalues : ι → ℝ)
      (eigenbasis : Module.Basis ι ℝ (ι → ℝ)),
    ∀ p, coefficient.mulVec (eigenbasis p) =
      eigenvalues p • eigenbasis p

Definition

Riemann initial data

Riemann initial data take the constant value qLq_{\mathrm L} for x<0x<0 and the constant value qRq_{\mathrm R} for x>0x>0. The value at x=0x=0 is free.

Lean definition

    {State : Type*} (data : ℝ → State)
    (leftState rightState : State) : Prop :=
  (∀ x : ℝ, x < 0 → data x = leftState) ∧
    (∀ x : ℝ, 0 < x → data x = rightState)

Probability and random matrices

Definition

Covariance of two random variables

For integrable X,YX,Y, write Xc=X−E[X]X_c=X-\mathbb E[X] and Yc=Y−E[Y]Y_c=Y-\mathbb E[Y]. If their centered product is integrable, the covariance is Cov⁡(X,Y)=E[XcYc]\operatorname{Cov}(X,Y)=\mathbb E[X_cY_c].

Lean definition
def covariance {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X Y : Ω → ℝ) : ℝ :=
  expectation μ (fun ω =>
    (X ω - expectation μ X) * (Y ω - expectation μ Y))

Definition

Sample second-moment matrix

For m>0m>0 sample vectors xix_i, the sample second-moment matrix is Σ^=1m∑i=1mxixiT.\widehat\Sigma=\frac1m\sum_{i=1}^m x_i x_i^{\mathsf T}. It uses the supplied sample vectors directly, with no sample-mean subtraction.

noncomputable def sampleCovariance {m n : ℕ} (X : Fin m → Fin n → ℝ) :
    Matrix (Fin n) (Fin n) ℝ := fun a b ↦
  (m : ℝ)⁻¹ * ∑ i, X i a * X i b

Definition

Sub-Gaussian random variable and ψ₂ gauge

A measurable real XX is sub-Gaussian if for some finite K>0K>0 the exponential-square moment is finite and E[exp⁡(X2/K2)]≤2.\mathbb E[\exp(X^2/K^2)]\le2. The ψ2\psi_2 gauge is the infimum of those scales, or +∞+\infty when none exists.

Lean definition
def PsiTwoAdmissible {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) (t : ℝ≥0∞) : Prop :=
  Measurable X ∧ t ≠ 0 ∧ t ≠ ∞ ∧
    Integrable (fun ω => Real.exp (X ω ^ 2 / t.toReal ^ 2)) μ ∧
      (∫ ω, Real.exp (X ω ^ 2 / t.toReal ^ 2) ∂μ) ≤ 2

/-- The extended ψ₂ gauge of a measurable real-valued function. -/
noncomputable def PsiTwoGauge {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : ℝ≥0∞ :=
  sInf {t : ℝ≥0∞ | PsiTwoAdmissible μ X t}

/-! The source-facing name for the `ψ₂` norm.  The extended value records
non-sub-Gaussian variables by `∞`; Definition 2.5.6 uses its finite part. -/
noncomputable def PsiTwoNorm {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : ℝ≥0∞ :=
  PsiTwoGauge μ X

/-! A random variable is sub-Gaussian when it is measurable and satisfies
property (iv) of Proposition 2.5.2 at some positive scale.  The equivalence of
properties (i)--(iv) below makes the chosen representative immaterial. -/
def IsSubGaussian {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : Prop :=
  Measurable X ∧ ∃ K : ℝ, 0 < K ∧ SubGaussianSquarePoint μ X K

Definition

Convex program

In this minimization convention the objective is convex, every equality hi(x)=0h_i(x)=0 has affine hih_i, and every inequality gj(x)≥0g_j(x)\ge0 has concave gjg_j. These properties apply on the functions’ declared domains.

Lean definition
def IsConvexProgramOnDomains {X : Type} [AddCommGroup X] [Module ℝ X]
    {ε ι : Type} (objectiveDomain : Set X)
    (equalityDomain : ε → Set X) (inequalityDomain : ι → Set X)
    (objective : X → ℝ) (equality : ε → X → ℝ)
    (inequality : ι → X → ℝ) : Prop :=
  ConvexOn ℝ objectiveDomain objective ∧
    (∀ k, IsAffineOn (equalityDomain k) (equality k)) ∧
    ∀ k, ConcaveOn ℝ (inequalityDomain k) (inequality k)

Definition

Orthonormal columns

A real matrix UU has orthonormal columns if each column has Euclidean length one and distinct columns have zero inner product. Equivalently, UTU=IU^{\mathsf T}U=I.

Lean definition
def HasOrthonormalColumns {m n : ℕ} (U : Fin m → Fin n → ℝ) : Prop :=
  ∀ j k : Fin n, ∑ i : Fin m, U i j * U i k = if j = k then 1 else 0

Definition

Subspace embedding in the squared-norm convention

A linear sketch SS is an ε\varepsilon-embedding in the squared-norm convention if (1−ε)∥y∥22≤∥Sy∥22≤(1+ε)∥y∥22(1-\varepsilon)\|y\|_2^2\le\|Sy\|_2^2\le(1+\varepsilon)\|y\|_2^2 for every yy in the subspace. For orthonormal UU spanning that subspace, this is equivalent to ∥(SU)T(SU)−I∥2≤ε\|(SU)^{\mathsf T}(SU)-I\|_2\le\varepsilon.

Lean definition
def gramEmbeddingCriterion : Prop :=
  ∀ (m d t : ℕ) (U : Matrix (Fin m) (Fin d) ℝ)
    (B : Matrix (Fin t) (Fin d) ℝ), HasOrthonormalColumns U →
    ∀ ε : ℝ, 0 < ε → ε < 1 →
      opNorm2 (fun i j => rowGram U i j - rowSketchGram B i j) =
        opNorm2 (fun i j => idMatrix d i j - rowSketchGram B i j) ∧
      (opNorm2 (fun i j => idMatrix d i j - rowSketchGram B i j) ≤ ε ↔
        ∀ x : Fin d → ℝ,
