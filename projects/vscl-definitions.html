Rounding and error analysis

Definition

Floating-point model and unit roundoff

In the standard relative-error model, a rounded operation with exact result z returns z(1 + δ) with |δ| ≤ u. The bound u is the unit roundoff. VSCL’s model supplies addition, subtraction, multiplication, division with a nonzero divisor, and square root on nonnegative inputs. It also requires exact addition from zero.

Lean definition
structure FPModel where
  u : ℝ
  u_nonneg : 0 ≤ u

  fl_add : ℝ → ℝ → ℝ
  fl_sub : ℝ → ℝ → ℝ
  fl_mul : ℝ → ℝ → ℝ
  fl_div : ℝ → ℝ → ℝ
  fl_sqrt : ℝ → ℝ

  /-- Additional exactness law: `fl(0 + x) = x`.

      This is not a consequence of the relative-error standard model above.
      It is included explicitly because tight recursive-summation constants use
      the first addition from zero as exact. -/
  fl_add_zero : ∀ x : ℝ, fl_add 0 x = x

  model_add :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_add x y = (x + y) * (1 + δ)

  model_sub :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_sub x y = (x - y) * (1 + δ)

  model_mul :
    ∀ x y, ∃ δ : ℝ,
      |δ| ≤ u ∧
      fl_mul x y = (x * y) * (1 + δ)

  model_div :
    ∀ x y, y ≠ 0 →
      ∃ δ : ℝ,
        |δ| ≤ u ∧
        fl_div x y = (x / y) * (1 + δ)

  model_sqrt :
    ∀ x, 0 ≤ x →
      ∃ δ : ℝ,
        |δ| ≤ u ∧
        fl_sqrt x = Real.sqrt x * (1 + δ)

Definition

Rounding factor γₖ

For unit roundoff u and a nonnegative integer k with ku < 1, define γₖ = ku/(1 − ku). The condition ku < 1 is written gammaValid in Lean and keeps the denominator positive.

Lean definition
noncomputable def gamma (fp : FPModel) (n : ℕ) : ℝ :=
  (n * fp.u) / (1 - n * fp.u)

/-- Well-definedness guard for `gamma`.
    The denominator `1 - n * u` is positive iff `n * u < 1`.
    All lemmas that use `gamma` in a meaningful bound require this hypothesis.
    In practice this holds for any realistic algorithm depth, since
    u ≈ 2⁻⁵³ in double precision. -/
def gammaValid (fp : FPModel) (n : ℕ) : Prop :=
  (n : ℝ) * fp.u < 1

Definition

Backward error

A computed output has backward error bounded by ε in an input norm if there is a change Δa with ‖Δa‖ ≤ ε for which the computed output equals the exact output f(a + Δa). A componentwise bound places a separate limit on each entry of Δa.

Lean definition
def normwiseBackwardErrorBoundedVec (n m : ℕ)
    (normIn : (Fin n → ℝ) → ℝ)
    (f : (Fin n → ℝ) → (Fin m → ℝ))
    (a : Fin n → ℝ) (xhat : Fin m → ℝ) (ε : ℝ) : Prop :=
  ∃ Δa : Fin n → ℝ, normIn Δa ≤ ε ∧ f (fun i => a i + Δa i) = xhat

Lean definition

Definition

Forward error

Forward error measures the difference between the computed output and the exact output for the original input. The relative version divides the size of that difference by the size of the exact output when the latter is nonzero.

Lean definition
noncomputable def forwardErrorBounded (f : ℝ → ℝ) (a xhat ε : ℝ) : Prop :=
  relError xhat (f a) ≤ ε

Matrices and factorizations

Definition

Operator 2-norm

The operator 2-norm ‖A‖₂ is the supremum of ‖Ax‖₂ over vectors x of Euclidean length one. It equals the largest singular value when the domain has positive dimension.

Lean definition
noncomputable def opNorm2 {n : ℕ} (M : Fin n → Fin n → ℝ) : ℝ :=
  @norm (Matrix (Fin n) (Fin n) ℝ)
    Matrix.instL2OpNormedAddCommGroup.toNorm
    (M : Matrix (Fin n) (Fin n) ℝ)

Lean definition

Definition

Matrix infinity norm

The matrix infinity norm is the largest absolute row sum, maxᵢ Σⱼ |Aᵢⱼ|. It is the operator norm for the vector infinity norm.

Lean definition
noncomputable def infNorm {n : ℕ} (A : Fin n → Fin n → ℝ) : ℝ :=
  letI := Matrix.linftyOpNormedRing (n := Fin n) (α := ℝ)
  ‖(Matrix.of A : Matrix (Fin n) (Fin n) ℝ)‖

Lean definition

Definition

Frobenius norm

The Frobenius norm of a matrix is the Euclidean length of its array of entries, ‖A‖F = √(Σᵢⱼ Aᵢⱼ²) for real A. The squared norm is the sum under the square root.

Lean definition
noncomputable def frobNormSq {m n : ℕ} (A : RMatFn m n) : ℝ :=
  ∑ i : Fin m, ∑ j : Fin n, A i j ^ 2

/-- **Frobenius norm** as a Mathlib-backed compatibility wrapper for the
    library's function-shaped matrices.  The source of truth is Mathlib's
    Frobenius norm on `Matrix`, not a separate local norm definition. -/
noncomputable abbrev frobNorm {m n : ℕ} (A : RMatFn m n) : ℝ :=
  ‖(Matrix.of A : RMat m n)‖

Definition

Column Euclidean norm

The norm of column j is √(Σᵢ Aᵢⱼ²) for a real matrix. A columnwise error estimate compares this norm for each perturbation column to the norm of the corresponding input column.

Lean definition
noncomputable def columnFrob {m p : ℕ} (A : Fin m → Fin p → ℝ)
    (j : Fin p) : ℝ :=
  frobNorm (fun i (_ : Fin 1) => A i j)

Definition

Matrix condition number in the 2-norm

For an invertible matrix A, κ₂(A) = ‖A‖₂‖A⁻¹‖₂. The Lean definition takes the inverse as an argument. A theorem supplies any required inverse certificate.

Lean definition
noncomputable def kappa2 {n : ℕ}
    (A Ainv : Fin n → Fin n → ℝ) : ℝ :=
  opNorm2 A * opNorm2 Ainv

Definition

Orthogonal matrix

A real square matrix Q is orthogonal if its transpose is its inverse. Equivalently, both QᵀQ and QQᵀ are the identity.

Lean definition
def IsOrthogonal (n : ℕ) (U : Fin n → Fin n → ℝ) : Prop :=
  IsInverse n U (matTranspose U)

Lean definition

Definition

Upper-trapezoidal matrix

A rectangular matrix R is upper trapezoidal if Rᵢⱼ = 0 for i > j. In a square matrix this condition is upper triangularity.

Lean definition
def IsUpperTrapezoidal (m p : ℕ) (R : Fin m → Fin p → ℝ) : Prop :=
  ∀ i j, j.val < i.val → R i j = 0

Lean definition

Definition

Columnwise QR backward error

Given the input A, an upper-trapezoidal R̂, and an orthogonal Q, the columnwise backward-error contract at c asks for a perturbation ΔA with A + ΔA = QR̂ and ‖ΔA[:, j]‖₂ ≤ c‖A[:, j]‖₂ for every column j.

Lean definition
structure HouseholderQRBackwardError (m n : Nat)
    (A : Fin m -> Fin n -> Real) (Q : Fin m -> Fin m -> Real)
    (R_hat : Fin m -> Fin n -> Real) (c : Real) : Prop where
  upper : IsUpperTrapezoidal m n R_hat
  orth : IsOrthogonal m Q
  result : Exists fun dA : Fin m -> Fin n -> Real =>
    (forall i j, A i j + dA i j = matMulRect m m n Q R_hat i j) /\
    (forall j, columnFrob dA j <= c * columnFrob A j)

Lean definition

Definition

Componentwise QR backward error

For an upper-trapezoidal R̂ and an orthogonal Q, the contract requires A + ΔA = QR̂ and ‖ΔA‖F ≤ c_norm. It also requires a nonnegative matrix G of Frobenius norm one with |ΔA| ≤ c_comp G|A| entrywise.

Lean definition
structure HouseholderQRComponentwiseBackwardError (m n : Nat)
    (A : Fin m -> Fin n -> Real) (Q : Fin m -> Fin m -> Real)
    (R_hat : Fin m -> Fin n -> Real) (c_norm c_comp : Real) : Prop where
  upper : IsUpperTrapezoidal m n R_hat
  orth : IsOrthogonal m Q
  result : Exists fun dA : Fin m -> Fin n -> Real =>
    Exists fun G : Fin m -> Fin m -> Real =>
      (forall i j, A i j + dA i j = matMulRect m m n Q R_hat i j) /\
      frobNorm dA <= c_norm /\
      (forall i j, 0 <= G i j) /\
      frobNorm G = 1 /\
      (forall i j, |dA i j| <=
        c_comp * matMulRect m m n G (fun a b => |A a b|) i j)

Definition

LU factorization

An LU factorization here is a product A = LU with L lower triangular and ones on its diagonal, and U upper triangular.

Lean definition
structure LUFactSpec (n : ℕ) (A L : Fin n → Fin n → ℝ) (U : Fin n → Fin n → ℝ) : Prop where
  /-- L is unit lower triangular: diagonal entries are 1. -/
  L_diag : ∀ i : Fin n, L i i = 1
  /-- L is lower triangular: entries above diagonal are 0. -/
  L_upper_zero : ∀ i j : Fin n, i.val < j.val → L i j = 0
  /-- U is upper triangular: entries below diagonal are 0. -/
  U_lower_zero : ∀ i j : Fin n, j.val < i.val → U i j = 0
  /-- A = L * U: the product recovers A exactly. -/
  product_eq : ∀ i j : Fin n, ∑ k : Fin n, L i k * U k j = A i j

Lean definition

Definition

Componentwise LU backward error

The computed factors L̂ and Û have the LU triangular shapes, and each entry of L̂Û − A is bounded in magnitude by the corresponding entry of ε|L̂||Û|. The absolute values on the factors are taken entry by entry.

Lean definition
structure LUBackwardError (n : ℕ) (A L_hat U_hat : Fin n → Fin n → ℝ)
    (ε : ℝ) : Prop where
  /-- L̂ is unit lower triangular. -/
  L_diag : ∀ i : Fin n, L_hat i i = 1
  /-- L̂ is lower triangular. -/
  L_upper_zero : ∀ i j : Fin n, i.val < j.val → L_hat i j = 0
  /-- Û is upper triangular. -/
  U_lower_zero : ∀ i j : Fin n, j.val < i.val → U_hat i j = 0
  /-- Componentwise backward error: |L̂Û - A| ≤ ε|L̂||Û|. -/
  backward_bound : ∀ i j : Fin n,
    |∑ k : Fin n, L_hat i k * U_hat k j - A i j| ≤
      ε * ∑ k : Fin n, |L_hat i k| * |U_hat k j|

Definition

Symmetric positive definite matrix

A real matrix A is symmetric positive definite if A = Aᵀ and xᵀAx > 0 for every nonzero real vector x.

Lean definition
def IsSymPosDef (n : ℕ) (A : Fin n → Fin n → ℝ) : Prop :=
  (∀ i j : Fin n, A i j = A j i) ∧
  (∀ x : Fin n → ℝ, (∃ i : Fin n, x i ≠ 0) →
    0 < ∑ i : Fin n, ∑ j : Fin n, x i * A i j * x j)

Definition

Least-squares residual and objective

For data A and b, the least-squares residual can be written Ax − b. The squared objective is ‖Ax − b‖₂². The same minimizers minimize ‖Ax − b‖₂ because squaring is increasing on nonnegative numbers.

Lean definition
noncomputable def lsResidual {m n : ℕ} (A : Fin m → Fin n → ℝ)
    (b : Fin m → ℝ) (x : Fin n → ℝ) : Fin m → ℝ :=
  fun i => rectMatMulVec A x i - b i
/-- Squared least-squares objective `||A x - b||₂²`. -/
noncomputable def lsObjective {m n : ℕ} (A : Fin m → Fin n → ℝ)
    (b : Fin m → ℝ) (x : Fin n → ℝ) : ℝ :=
  vecNorm2Sq (lsResidual A b x)

Finite-volume methods

Definition

Cell average

For an integrable field q on a nondegenerate interval [a,b], its cell average is (b − a)⁻¹ times its integral from a to b. For a vector field the same formula averages all components.

Lean definition
noncomputable def oneDimensionalCellAverage
    {E : Type*} [NormedAddCommGroup E] [NormedSpace ℝ E]
    (field : ℝ → E) (left right : ℝ) : E :=
  (right - left)⁻¹ • ∫ x in left..right, field x

Lean definition

Definition

Finite-volume flux update

For positive cell volume V, the next cell average is the old average minus Δt/V times the net outward numerical flux, where Δt is the time step.

Lean definition
noncomputable def finiteVolumeCellAverageUpdate
    {E : Type*} [AddCommGroup E] [Module ℝ E]
    (timeStep cellVolume : ℝ) (oldAverage netOutwardFlux : E) : E :=
  oldAverage - (timeStep / cellVolume) • netOutwardFlux

Lean definition

Definition

Local conservation at an interface

For each time and shared face, the outward numerical flux from one adjacent cell must be the negative of the outward numerical flux from the other cell.

Lean definition
def IsLocallyConservative
    {Cell Face Time Value : Type*} [Neg Value]
    (left right : Face → Cell) (flux : Time → Cell → Face → Value) : Prop :=
  ∀ time face, flux time (left face) face = -flux time (right face) face

Definition

Hyperbolicity of a real matrix

A real square matrix is hyperbolic in the conservation-law sense if it has a basis of real eigenvectors with real eigenvalues. The eigenvalues can repeat.

Lean definition
def IsRealHyperbolicMatrix {ι : Type*} [Fintype ι]
    (coefficient : Matrix ι ι ℝ) : Prop :=
  ∃ (eigenvalues : ι → ℝ)
      (eigenbasis : Module.Basis ι ℝ (ι → ℝ)),
    ∀ p, coefficient.mulVec (eigenbasis p) =
      eigenvalues p • eigenbasis p

Definition

Hyperbolicity of a flux at a state

A flux is hyperbolic at a state if its derivative at that state exists and its matrix in the standard coordinates has a basis of real eigenvectors with real eigenvalues.

Lean definition
def IsHyperbolicFluxAt {m : ℕ}
    (flux : (Fin m → ℝ) → (Fin m → ℝ)) (state : Fin m → ℝ) : Prop :=
  ∃ derivative : (Fin m → ℝ) →L[ℝ] (Fin m → ℝ),
    HasFDerivAt flux derivative state ∧
      IsRealHyperbolicMatrix (LinearMap.toMatrix' derivative.toLinearMap)

Definition

Riemann initial data

The initial field is constant with value qL for x < 0 and constant with value qR for x > 0. This definition leaves the value at x = 0 free.

Lean definition
def IsRiemannData
    {State : Type*} (data : ℝ → State)
    (leftState rightState : State) : Prop :=
  (∀ x : ℝ, x < 0 → data x = leftState) ∧
    (∀ x : ℝ, 0 < x → data x = rightState)

Probability and random matrices

Definition

Covariance of two random variables

For integrable variables with integrable centered product, the covariance of X and Y is the expectation of (X − E[X])(Y − E[Y]).

Lean definition
def covariance {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X Y : Ω → ℝ) : ℝ :=
  expectation μ (fun ω =>
    (X ω - expectation μ X) * (Y ω - expectation μ Y))

Lean definition

Definition

Sample second-moment matrix

For m > 0 sample vectors x₁,…,xₘ, the sample second-moment matrix is the average of their outer products, (1/m) Σᵢ xᵢxᵢᵀ. The implementation uses the supplied sample vectors directly, with no sample-mean subtraction.

Lean definition
noncomputable def sampleCovariance {m n : ℕ} (X : Fin m → Fin n → ℝ) :
    Matrix (Fin n) (Fin n) ℝ := fun a b ↦
  (m : ℝ)⁻¹ * ∑ i, X i a * X i b

Lean definition

Definition

Sub-Gaussian random variable and ψ₂ gauge

A measurable real random variable X is sub-Gaussian when there is a finite K > 0 for which E[exp(X²/K²)] ≤ 2 with a finite integral. Its ψ₂ gauge is the infimum of such scales, or infinity when no scale works.

Lean definition
def PsiTwoAdmissible {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) (t : ℝ≥0∞) : Prop :=
  Measurable X ∧ t ≠ 0 ∧ t ≠ ∞ ∧
    Integrable (fun ω => Real.exp (X ω ^ 2 / t.toReal ^ 2)) μ ∧
      (∫ ω, Real.exp (X ω ^ 2 / t.toReal ^ 2) ∂μ) ≤ 2

/-- The extended ψ₂ gauge of a measurable real-valued function. -/
noncomputable def PsiTwoGauge {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : ℝ≥0∞ :=
  sInf {t : ℝ≥0∞ | PsiTwoAdmissible μ X t}

/-! The source-facing name for the `ψ₂` norm.  The extended value records
non-sub-Gaussian variables by `∞`; Definition 2.5.6 uses its finite part. -/
noncomputable def PsiTwoNorm {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : ℝ≥0∞ :=
  PsiTwoGauge μ X

/-! A random variable is sub-Gaussian when it is measurable and satisfies
property (iv) of Proposition 2.5.2 at some positive scale.  The equivalence of
properties (i)--(iv) below makes the chosen representative immaterial. -/
def IsSubGaussian {Ω : Type*} [MeasurableSpace Ω]
    (μ : Measure Ω) (X : Ω → ℝ) : Prop :=
  Measurable X ∧ ∃ K : ℝ, 0 < K ∧ SubGaussianSquarePoint μ X K

Definition

Isotropic random vector

A real random vector is isotropic when its second-moment matrix E[XXᵀ] is the identity. For a centered vector this is equivalent to having identity covariance.

Lean definition
def IsIsotropic {Ω : Type*} [MeasurableSpace Ω] {n : ℕ}
    (μ : Measure Ω) (X : Fin n → Ω → ℝ) : Prop :=
  NumStability.HDP.Vector.Covariance.secondMomentMatrix μ X = 1

Definition

ε-net of the unit sphere

An ε-net of the unit sphere is a set of unit vectors such that each unit vector lies at distance at most ε from some point of the set.

Lean definition
def IsUnitSphereNet {E : Type*} [NormedAddCommGroup E]
    (ε : ℝ) (N : Set E) : Prop :=
  (∀ y ∈ N, ‖y‖ = 1) ∧
    ∀ x : E, ‖x‖ = 1 → ∃ y ∈ N, ‖x - y‖ ≤ ε

The internal covering number at radius ε is the least size of a set of centers in K whose closed ε-balls cover K. The library uses an extended natural number so that infinity records the absence of a finite cover.

Definition

Approximate isometry

A matrix A satisfies the approximate-isometry bound at δ when (1 − δ)‖x‖₂ ≤ ‖Ax‖₂ ≤ (1 + δ)‖x‖₂ for every x.

Lean definition
def ApproximateIsometryBounds {m n : ℕ}
    (A : Matrix (Fin m) (Fin n) ℝ) (δ : ℝ) : Prop :=
  ∀ x : EuclideanSpace ℝ (Fin n),
    (1 - δ) * ‖x‖ ≤ ‖Matrix.toEuclideanLin A x‖ ∧
      ‖Matrix.toEuclideanLin A x‖ ≤ (1 + δ) * ‖x‖

Definition

Sub-exponential ψ₁ gauge

The ψ₁ gauge in this convention is the infimum of admissible positive scales K. A scale is admissible when X is measurable and E[exp(λ|X|)] ≤ exp(Kλ), with a finite integral, for every 0 ≤ λ ≤ 1/K.

Lean definition
def PsiOnePropertyThreeAdmissible {Omega : Type*} [MeasurableSpace Omega]
    (mu : Measure Omega) (X : Omega -> Real) (t : ENNReal) : Prop :=
  t ≠ 0 ∧ t ≠ ⊤ ∧ SubExponentialAbsoluteMGFLocal mu X t.toReal

/-- The literal property-(c) infimum named in the prose of Definition 2.7.5. -/
noncomputable def PsiOnePropertyThreeGauge
    {Omega : Type*} [MeasurableSpace Omega]
    (mu : Measure Omega) (X : Omega -> Real) : ENNReal :=
  sInf {t : ENNReal | PsiOnePropertyThreeAdmissible mu X t}

Optimization

Definition

Convex program

In this sign convention, a minimization program is convex when the objective is convex, every equality constraint is affine, and every constraint of the form g(x) ≥ 0 has concave g. These properties are stated on the functions’ declared domains.

Lean definition
def IsConvexProgramOnDomains {X : Type} [AddCommGroup X] [Module ℝ X]
    {ε ι : Type} (objectiveDomain : Set X)
    (equalityDomain : ε → Set X) (inequalityDomain : ι → Set X)
    (objective : X → ℝ) (equality : ε → X → ℝ)
    (inequality : ι → X → ℝ) : Prop :=
  ConvexOn ℝ objectiveDomain objective ∧
    (∀ k, IsAffineOn (equalityDomain k) (equality k)) ∧
    ∀ k, ConcaveOn ℝ (inequalityDomain k) (inequality k)

Randomized numerical linear algebra

Definition

Orthonormal columns

A real matrix U has orthonormal columns if each column has Euclidean length one and every two distinct columns have inner product zero. In matrix form, UᵀU = I.

Lean definition
def HasOrthonormalColumns {m n : ℕ} (U : Fin m → Fin n → ℝ) : Prop :=
  ∀ j k : Fin n, ∑ i : Fin m, U i j * U i k = if j = k then 1 else 0

Lean definition

Definition

Leverage score

Given a matrix U whose columns form an orthonormal basis of a subspace, row i has leverage score equal to its squared Euclidean length, or equivalently the ith diagonal entry of the projector UUᵀ.

Lean definition
noncomputable def leverageScore {m n : ℕ} (U : Fin m → Fin n → ℝ)
    (i : Fin m) : ℝ :=
  rowNormSq U i

Lean definition

Definition

Leverage sampling probability

For an orthonormal basis U of positive width d, the probability of selecting row i is its leverage score divided by d. The row scores sum to d.

Lean definition
noncomputable def leverageScoreProb {m n : ℕ} (U : Fin m → Fin n → ℝ)
    (i : Fin m) : ℝ :=
  rowSqNormProb U i

Lean definition

Definition

Subspace embedding in the squared-norm convention

A linear sketch S is an ε-embedding for a subspace if it preserves every squared Euclidean length in that subspace within factors 1 − ε and 1 + ε. If U has orthonormal columns spanning the subspace, this is equivalent to ‖(SU)ᵀ(SU) − I‖₂ ≤ ε.

Lean definition
def gramEmbeddingCriterion : Prop :=
  ∀ (m d t : ℕ) (U : Matrix (Fin m) (Fin d) ℝ)
    (B : Matrix (Fin t) (Fin d) ℝ), HasOrthonormalColumns U →
    ∀ ε : ℝ, 0 < ε → ε < 1 →
      opNorm2 (fun i j => rowGram U i j - rowSketchGram B i j) =
        opNorm2 (fun i j => idMatrix d i j - rowSketchGram B i j) ∧
      (opNorm2 (fun i j => idMatrix d i j - rowSketchGram B i j) ≤ ε ↔
        ∀ x : Fin d → ℝ,
          |vecNorm2Sq (B.mulVec x) - vecNorm2Sq x| ≤ ε * vecNorm2Sq x) ∧
      (opNorm2 (fun i j => idMatrix d i j - rowSketchGram B i j) ≤ ε ↔
        ∀ x : Fin d → ℝ,
          (1 - ε) * vecNorm2Sq x ≤ vecNorm2Sq (B.mulVec x) ∧
          vecNorm2Sq (B.mulVec x) ≤ (1 + ε) * vecNorm2Sq x)
