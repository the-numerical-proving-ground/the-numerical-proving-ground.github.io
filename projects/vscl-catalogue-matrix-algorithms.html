  • Theorem 8.3

    Row-specific backward error for backward substitution

    Let UU be a nonsingular real upper-triangular matrix and assume nu<1nu<1. Rounded backward substitution solves (U+ΔU)x^=b(U+\Delta U)\widehat x=b, with ∣ΔUii∣≤γn−i∣Uii∣,∣ΔUij∣≤γj−i∣Uij∣(j>i).\begin{gathered}|\Delta U_{ii}|\le\gamma_{n-i}|U_{ii}|,\\ |\Delta U_{ij}|\le\gamma_{j-i}|U_{ij}|\quad(j>i).\end{gathered} Indices start at zero, and ΔU\Delta U vanishes below the diagonal.

    Definitions used (2)
    Floating-point model and unit roundoff
    In the standard relative-error model, a rounded operation with exact result zz returns z(1+δ)z(1+\delta) for some ∣δ∣≤u|\delta|\le u. The bound uu is the unit roundoff. VSCL’s model supplies addition, subtraction, multiplication, division with a nonzero divisor, and square root on nonnegative inputs. It also requires exact addition from zero.

    For unit roundoff uu and a nonnegative integer kk such that ku<1ku<1, define γk=ku1−ku.\gamma_k=\frac{ku}{1-ku}. In Lean, the condition that keeps the denominator positive is called gammaValid.
