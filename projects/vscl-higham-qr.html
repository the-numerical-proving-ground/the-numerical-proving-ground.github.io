Householder QR

Theorem 19.4

Columnwise backward stability of Householder QR

Let A be a real m × n matrix with 0 < n ≤ m. The computed upper-trapezoidal factor R̂ admits an exact orthogonal factor Q and a perturbation ΔA such that A + ΔA = QR̂. In every column, the Euclidean norm of ΔA is at most γₖ times that of the corresponding column of A, where k = 3n(11m + 23) and γₖ = ku/(1 − ku).

The proof assumes ku < 1 in the floating-point model with unit roundoff u. The factorization result allows rank-deficient inputs.

Lean statement
theorem householder_qr_backward_error
    (fp : FPModel) (m n : Nat) (A : Fin m -> Fin n -> Real)
    (hn : 0 < n) (hnm : n <= m)
    (hvalid : gammaValid fp (n * householderConstructApplyGammaIndex m)) :
    HouseholderQRBackwardError m n A
      (fl_householderQRPanel_Q fp m n A)
      (fl_householderQRPanel_R fp m n A)
      (gamma_tilde fp m n)

Theorem 19.5

Backward error of a Householder QR solve

Let A be a nonsingular real n × n matrix with n > 0, and let x̂ be computed by the Householder QR solver for Ax = b. Under the smallness condition below, x̂ solves (A + ΔA)x̂ = b + Δb exactly. Lean bounds each column of ΔA relative to that column of A, and bounds Δb relative to b, all in the Euclidean norm.

Assume ku < 1 and √n γₖ κ₂(A) < 1, where k = 3n(11n + 23) and u is the unit roundoff. These conditions guarantee nonzero computed pivots. The right-hand side coefficient is γₖ and the matrix coefficient is γₖ + γₙ(1 + γₖ).

Lean statement
theorem higham19_theorem19_5_actual_columnwise_backward_error_of_source_small
    (fp : FPModel) (n : Nat)
    (A : Fin n -> Fin n -> Real) (b : Fin n -> Real)
    (hn : 0 < n)
    (hsource : Function.Injective (rectMatMulVec A))
    (hvalid : gammaValid fp
      (n * householderConstructApplyGammaIndex n))
    (hsmall :
      Real.sqrt (n : Real) *
          gamma fp (n * householderConstructApplyGammaIndex n) *
          higham19QRSourceKappa2 A < 1) :

      (fl_householderQR_solve fp n A b)

Theorem 19.6

Row-scaled backward error for column-pivoted QR

For a real m × n matrix with 0 < n ≤ m, the computed column permutation Π and upper-trapezoidal factor R̂ satisfy AΠ + ΔA = QR̂ for an exact orthogonal Q. The bound on entry (i, j) of ΔA is proportional to j² (with columns numbered from 1) times the largest absolute entry in row i across the stored stages.

The bound is for the staged Householder implementation with column pivoting. It assumes three explicit roundoff conditions, including a smallness condition on the coefficient for growth through the swaps.

Lean statement
theorem higham19_6_sourceConstructed_actual_closed_linearRate
    (fp : FPModel) {m n : ℕ} (hn : 0 < n) (hmn : n ≤ m)
    (A : Fin m → Fin n → ℝ)
    (hvalid : gammaValid fp (11 * m + 23))
    (hgammaHalf : gamma fp (m + 1) ≤ (1 : ℝ) / 2)
    (hsmall : sourceConstructedPivotedStoredQRPivotGrowthSmall fp m) :
    let Q := sourceConstructedPivotedStoredQRQ fp hn hmn A
    let R := fl_sourceConstructedPivotedStoredQRMatrixSeq fp hn hmn A n
    let pi := sourceConstructedPivotedStoredQRPi fp hn hmn A
    let dA := sourceConstructedPivotedStoredQRdA fp hn hmn A
    IsOrthogonal m Q ∧
      IsUpperTrapezoidal m n R ∧
      (∀ i j, R i j =
        matMulRect m m n (matTranspose Q)
          (fun a b => Wave13.columnPermuteMatrix A pi a b + dA a b) i j) ∧
      (∀ i j, Wave13.columnPermuteMatrix A pi i j + dA i j =
        matMulRect m m n Q R i j) ∧
      ∀ i j, |dA i j| ≤
        ((j.val : ℝ) + 1) ^ 2 *
          (5 * sourceConstructedPivotedStoredQRLinearGammaTilde fp m) *
            sourceConstructedPivotedStoredQRPrintedAlphaScale
              fp hn hmn A i

Equation (19.7)

One orthogonal factor for the matrix and right-hand side

This result tracks how local rounding perturbations accumulate across a sequence of orthogonal transformations applied to a matrix and a right-hand side. It supplies the common exact orthogonal factor used in the subsequent error bounds.

Lean statement
theorem rect_orthogonal_columnwise_vector_sequence_geometric (m n r : ℕ)
    (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ)
    (A_hat : ℕ → Fin m → Fin n → ℝ)
    (b_hat : ℕ → Fin m → ℝ)
    (P : ℕ → Fin m → Fin m → ℝ)
    (ΔPA : ℕ → Fin n → Fin m → Fin m → ℝ)
    (ΔPb : ℕ → Fin m → Fin m → ℝ)
    (c : ℝ) (hc : 0 ≤ c)
    (hInitA : A_hat 0 = A)
    (hInitb : b_hat 0 = b)
    (hP : ∀ k, k < r → IsOrthogonal m (P k))
    (hΔPA : ∀ k, k < r → ∀ j : Fin n, frobNorm (ΔPA k j) ≤ c)
    (hΔPb : ∀ k, k < r → frobNorm (ΔPb k) ≤ c)
    (hNextA : ∀ k, k < r → ∀ i j,
      A_hat (k + 1) i j =
        matMulVec m (fun a b => P k a b + ΔPA k j a b)
          (fun a => A_hat k a j) i)
    (hNextb : ∀ k, k < r →
      b_hat (k + 1) =
        matMulVec m (fun a b => P k a b + ΔPb k a b) (b_hat k)) :
    ∃ (Q : Fin m → Fin m → ℝ)
        (ΔA : Fin m → Fin n → ℝ) (Δb : Fin m → ℝ),
      IsOrthogonal m Q ∧
      (∀ i j, A_hat r i j =
        matMulRectLeft (matTranspose Q) (fun a b => A a b + ΔA a b) i j) ∧
      (∀ i, b_hat r i =
        matMulVec m (matTranspose Q) (fun a => b a + Δb a) i) ∧
      (∀ j : Fin n,
        vecNorm2 (fun i => ΔA i j) ≤
          ((1 + c) ^ r - 1) * vecNorm2 (fun i => A i j)) ∧
      vecNorm2 Δb ≤ ((1 + c) ^ r - 1) * vecNorm2 b

Givens QR

Theorem 19.10

Columnwise backward stability of Givens QR

Let A be a real m × n matrix with 0 < n ≤ m. If 8u < 1, the staged Givens algorithm’s upper-trapezoidal output R̂ satisfies A + ΔA = QR̂ for some exact orthogonal Q. For each column j, the Euclidean norm of ΔA’s jth column is at most a proved coefficient times that of A’s jth column.

The coefficient depends on m, n, and the unit roundoff u. The Lean proof gives a conservative coefficient for its particular rotation schedule.

Lean statement
theorem givens_qr_backward_error
    (fp : FPModel) (m n : Nat) (A : Fin m -> Fin n -> Real)
    (_hn : 0 < n) (_hnm : n <= m)
    (hvalid : gammaValid fp 8) :
    GivensQRBackwardError m n A
      (Classical.choose
        (fl_givensQRStageFold_sequence_columnFrob_backward_error_uniform
          fp m n A (givensQRStageCount m n) hvalid))
      (fl_givensQRStageFold fp m n (givensQRStageCount m n) A)
      (gamma_tilde fp m n)

Modified Gram–Schmidt

Theorem 19.13

What modified Gram–Schmidt guarantees when it completes

For a real matrix of full column rank with at least as many rows as columns, assume the roundoff and conditioning bounds in the Lean statement. The rounded algorithm either encounters a zero pivot or gives bounds on the residual of Q̂R̂, the loss of orthogonality of Q̂, and the columnwise perturbation needed to pair R̂ with a factor with exactly orthonormal columns.

Formalized as a success-or-breakdown result. A separate Lean counterexample shows that full rank and the routine roundoff bounds alone allow a zero computed pivot in the abstract floating-point model.

Lean statement
theorem higham19_13_literal_mgs_source_rate_canonical_success_or_breakdown
    {m n : Nat}
    (fp : FPModel) (A : Fin m -> Fin n -> Real)
    (hnm : n <= m)
    (hfull : Function.Injective (rectMatMulVec A))
    (hm : gammaValid fp (2 * (m + 1)))
    (hmodelSmall :
      (((2 * (m + 1) : Nat) : Real) * fp.u <= 1 / 2))
    (hconditionSmall :
      Real.sqrt (n : Real) * mgsSourceRepairCoeff m n * fp.u *
          mgsSourceKappa2 A < 1) :
    LiteralMGSTheorem1913CanonicalOutcome m n fp A

Equation (19.32)

Reconstructing one exact Gram–Schmidt stage

This exact-arithmetic identity recovers the current stage matrix from the next one and a small triangular factor. The current pivot norm must be nonzero.

Lean statement
theorem sourceStage_matrix_recurrence {m n : Nat}
    (A : Fin m -> Fin n -> Real) (k : Fin n)
    (hdiag : Ne (gsColumnNorm2 (stageVectors A k.val k)) 0) :
    sourceStage A k.val =
      matMulRect m n n (sourceStage A (k.val + 1)) (stepR A k)

This result composes the one-stage identity to recover the input from an intermediate stage and the accumulated triangular factors. It applies to a prefix in which every pivot norm is nonzero.
