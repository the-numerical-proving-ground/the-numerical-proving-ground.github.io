Theorem 19.4

Columnwise backward stability of Householder QR

Let AA be a real m×nm\times n matrix with 0<n≤m0<n\le m. The computed upper-trapezoidal factor R^\widehat R admits an exactly orthogonal QQ and a perturbation ΔA\Delta A such that A+ΔA=QR^,∥ΔA:,j∥2≤γk∥A:,j∥2\begin{gathered}A+\Delta A=Q\widehat R,\\ \|\Delta A_{:,j}\|_2\le\gamma_k\|A_{:,j}\|_2\end{gathered} for every column jj. Here k=3n(11m+23)k=3n(11m+23) and γk=ku/(1−ku)\gamma_k=ku/(1-ku).

Definitions used (6)
Floating-point model and unit roundoff
In the standard relative-error model, a rounded operation with exact result zz returns z(1+δ)z(1+\delta) for some ∣δ∣≤u|\delta|\le u. The bound uu is the unit roundoff. VSCL’s model supplies addition, subtraction, multiplication, division with a nonzero divisor, and square root on nonnegative inputs. It also requires exact addition from zero.
Rounding factor γₖ
For unit roundoff uu and a nonnegative integer kk such that ku<1ku<1, define γk=ku1−ku.\gamma_k=\frac{ku}{1-ku}. In Lean, the condition that keeps the denominator positive is called gammaValid.
Column Euclidean norm
The Euclidean norm of column jj of a real matrix AA is ∥A:,j∥2=(∑iAij2)1/2\|A_{:,j}\|_2=(\sum_i A_{ij}^2)^{1/2}. A columnwise error bound compares this norm for each perturbation column to the corresponding input column norm.
Orthogonal matrix
A real square matrix QQ is orthogonal if its transpose is its inverse, so QTQ=QQT=IQ^{\mathsf T}Q=QQ^{\mathsf T}=I.
Upper-trapezoidal matrix
A rectangular matrix RR is upper trapezoidal if Rij=0R_{ij}=0 whenever i>ji>j. For a square matrix, this is upper triangularity.
Columnwise QR backward error
Given AA, upper-trapezoidal R^\widehat R, and orthogonal QQ, the columnwise backward-error contract at cc asks for a perturbation ΔA\Delta A with A+ΔA=QR^,∥ΔA:,j∥2≤c∥A:,j∥2\begin{gathered}A+\Delta A=Q\widehat R,\\\|\Delta A_{:,j}\|_2\le c\|A_{:,j}\|_2\end{gathered} for every column jj.

The proof assumes ku<1ku<1 in the floating-point model with unit roundoff uu. It allows rank-deficient inputs.

Theorem 19.5

Backward error of a Householder QR solve

Let AA be a nonsingular real n×nn\times n matrix with n>0n>0, and let x^\widehat x come from the rounded Householder QR solver for Ax=bAx=b. Under the conditions below, the following hold for every column jj. (A+ΔA)x^=b+Δb,∥ΔA:,j∥2≤cA∥A:,j∥2,∥Δb∥2≤cb∥b∥2.\begin{gathered}(A+\Delta A)\widehat x=b+\Delta b,\\ \|\Delta A_{:,j}\|_2\le c_A\|A_{:,j}\|_2,\\ \|\Delta b\|_2\le c_b\|b\|_2.\end{gathered}

Theorem 19.6

Row-scaled backward error for column-pivoted QR

For a real m×nm\times n matrix with 0<n≤m0<n\le m, the computed column permutation Π\Pi and upper-trapezoidal factor R^\widehat R satisfy AΠ+ΔA=QR^A\Pi+\Delta A=Q\widehat R for an exact orthogonal QQ. The bound on entry (i,j)(i,j) of ΔA\Delta A is proportional to j2j^2, with columns numbered from one, times the largest absolute entry in row ii across the stored stages.

Equation (19.7)

One orthogonal factor for the matrix and right-hand side

This result tracks the rounding perturbations across a sequence of orthogonal transformations applied to a matrix AA and right-hand side bb. One exact orthogonal factor accounts for both perturbed outputs.

theorem rect_orthogonal_columnwise_vector_sequence_geometric (m n r : ℕ)
    (A : Fin m → Fin n → ℝ) (b : Fin m → ℝ)
    (A_hat : ℕ → Fin m → Fin n → ℝ)
    (b_hat : ℕ → Fin m → ℝ)
    (P : ℕ → Fin m → Fin m → ℝ)
    (ΔPA : ℕ → Fin n → Fin m → Fin m → ℝ)
    (ΔPb : ℕ → Fin m → Fin m → ℝ)
    (c : ℝ) (hc : 0 ≤ c)
    (hInitA : A_hat 0 = A)
    (hInitb : b_hat 0 = b)
    (hP : ∀ k, k < r → IsOrthogonal m (P k))
    (hΔPA : ∀ k, k < r → ∀ j : Fin n, frobNorm (ΔPA k j) ≤ c)
    (hΔPb : ∀ k, k < r → frobNorm (ΔPb k) ≤ c)
    (hNextA : ∀ k, k < r → ∀ i j,
      A_hat (k + 1) i j =
        matMulVec m (fun a b => P k a b + ΔPA k j a b)
          (fun a => A_hat k a j) i)
    (hNextb : ∀ k, k < r →
      b_hat (k + 1) =
        matMulVec m (fun a b => P k a b + ΔPb k a b) (b_hat k)) :
    ∃ (Q : Fin m → Fin m → ℝ)
        (ΔA : Fin m → Fin n → ℝ) (Δb : Fin m → ℝ),
      IsOrthogonal m Q ∧
      (∀ i j, A_hat r i j =
        matMulRectLeft (matTranspose Q) (fun a b => A a b + ΔA a b) i j) ∧
      (∀ i, b_hat r i =
        matMulVec m (matTranspose Q) (fun a => b a + Δb a) i) ∧
      (∀ j : Fin n,
        vecNorm2 (fun i => ΔA i j) ≤
          ((1 + c) ^ r - 1) * vecNorm2 (fun i => A i j)) ∧
      vecNorm2 Δb ≤ ((1 + c) ^ r - 1) * vecNorm2 b

Theorem 19.13

What modified Gram–Schmidt guarantees when it completes

For a real matrix of full column rank with at least as many rows as columns, assume the roundoff and conditioning bounds in the Lean statement.
