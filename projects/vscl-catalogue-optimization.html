  • Chapter 1 · Definition

    Concavity as convexity of the negative

    A function f is concave on a convex set when f((1 − t)x + ty) ≥ (1 − t)f(x) + tf(y) for points x, y in the set and 0 ≤ t ≤ 1. Equivalently, −f is convex there.

    Library note

    A function is concave on a set exactly when its pointwise negative is convex there.

  • Chapter 1 · Definition

    The domains in a convex optimization problem

    In the book’s minimization convention, the objective is convex, equality constraint functions are affine, and the functions in nonnegative inequality constraints are concave. These conditions apply on their respective domains.

    Definitions used (1)
    Convex program
    In this sign convention, a minimization program is convex when the objective is convex, every equality constraint is affine, and every constraint of the form g(x) ≥ 0 has concave g. These properties are stated on the functions’ declared domains.
    Library note

    The convex-program classification uses the objective, equality, and inequality conditions on their respective declared domains.

    Convex sets and line segments

  • Equation (1.4)

    Convex functions and the line-segment inequality

    A real-valued function f on a convex domain is convex when f((1 − t)x + ty) ≤ (1 − t)f(x) + tf(y) for every pair x, y in the domain and 0 ≤ t ≤ 1.
